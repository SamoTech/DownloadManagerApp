# Quick Start Guide - Universal Download Manager

## Installation

### From Source
1. Clone the repository
2. Open in Android Studio
3. Sync Gradle
4. Build and run

## Usage

### Starting a Download
1. Tap + button
2. Select download type (Direct, Torrent, Video)
3. Enter URL
4. Start download

### Managing Downloads
- Pause/Resume
- Cancel
- Retry
- Delete
- Open
- Share

## Settings
- Max concurrent downloads
- Download speed limit
- Save location
- Network options
- Torrent settings
- Video preferences

## Supported Platforms
- All file types
- YouTube, Vimeo, Facebook, Instagram, Twitter, TikTok
- Magnet links, .torrent files
